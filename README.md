# Academic Lab

A structured, automated repository dedicated to accumulating and organizing academic knowledge and AI-assisted learning.

## Overview

This repository is designed to serve as a comprehensive learning and reference environment for academic studies. It leverages AI agents, web extraction tools, and structured documentation generators to systematically build a high-fidelity knowledge hub.

## Structure

- [knowledge-base](./knowledge-base/README.md): The central repository for all gathered documentation.
  - [collections](./knowledge-base/collections/README.md): Content source for documentation and blog collections.
  - [packages/preset](./knowledge-base/packages/preset/README.md): Custom Docusaurus preset for dynamic collection orchestration.
  - [packages/theme](./knowledge-base/packages/theme/README.md): Custom Docusaurus theme and stylesheet.
  - [apps/main](./knowledge-base/apps/main/README.md): Main documentation portal application.
- [config](./config/README.md): Contains [project.config.ts](./config/src/project.config.ts) for technical configurations.
- [LEARNING_CONTEXT.md](./LEARNING_CONTEXT.md): Contains the subjective goals and focus of the current study.
- [.agents](./.agents/README.md): Contains agent skills, automated workflows, plugins, and execution plans.

## Getting Started

To interact with Academic Lab or add new study plans, refer to the [plans directory](./.agents/plans/).
For agent context and operational rules, refer to the [Root Agent Context](./AGENTS.md).
